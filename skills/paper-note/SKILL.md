# 论文笔记成稿

把共读中形成的理解、证据和个人判断整理成以后能独立读懂、继续推敲的笔记。通常接在 `paper-assistant` 之后，也可整理用户提供的阅读记录。以已有成果为起点，按实际阅读范围成稿。

## 开始前

1. **接上共读材料。** 从当前对话、已有笔记和用户指定文件中取得论文题名与版本、解构结果、读者原话、讨论结论及未决问题。局部整理直接处理指定部分。只有缺失信息会改变核心判断时，才补核相应原文或向读者确认。
2. **读取保存约定。** 在用户的论文笔记存放位置查找并读取 `README`，获取目标文档、命名、索引、工具及状态维护要求；若其中指定样例，读取其当前版本。具体存放约定以本次请求及 README 为准。入口暂不可读时先完成正文，说明尚未完成的归档步骤。
3. **定位已有笔记。** 按论文标识、完整题名和版本核对已有文档。续写时先读当前正文，将新结论放回相关主题，保留用户手动修改、原话和批注。版本变化影响结论时，交代变化及其依据。

## 组织成三部分

### 一、速览

写出完整题名、作者、年份和理解内容所需的论文类型或版本信息。

用一小段“内容摘要（整理）”说明论文研究什么、核心思路是什么、得到什么结果，以及最重要的适用条件。概括范围与已核实的材料一致。

“我的结论”只收录读者已经表达或确认的判断，保留有价值的原话。读者修正了判断时，以最新确认的认识为当前结论，必要时注明原判断及修正缘由。AI 的概括和推断在正文标明来源；尚无个人判断时省略这一栏。

### 二、阅读笔记

按真正读过、讨论过的问题组织小节。每节先交代核心认识，再给必要的机制解释、证据和适用范围，使读者脱离聊天记录也能理解。标题体现问题或认识，段落之间有清楚的承接。

按材料选择需要的表达：
- 解释机制时，交代对象、输入、关键变化和结果；保留讨论中真正帮助理解的算例、公式或原图。
- 比较方法时，统一任务与实验条件；表格用于梳理职责、差异或证据。
- 判断收益时，保留指标口径、比较条件、负结果与局限，关键主张指向原文节、式、图表或页码。
- 整理讨论时，区分作者主张、AI 重建、读者判断和场景假设。新证据修正了认识，就更新当前结论；仍有分歧时留下具体问题及区分解释所需的证据。

取舍依据是内容是否帮助理解或改变判断。压缩重复解释和聊天往返，保留必要的推理、限定条件和未决点。综述可围绕分类与边界展开，方法论文可围绕机制与验证展开；章节数量随内容决定。

图、表、公式放在解释它们的段落附近，并说明读者应从中看到什么。原图注明图号与出处，自绘示意注明性质。核心结论不能只藏在图片里。

### 三、关键链接

集中保留原文及所读版本、作者项目或代码、阅读记录入口，以及少量直接相关的资源。正式文章、实验和复现结果已有实际产出时，链接到对应成果。来源收集日志和重复链接留在管理记录中。

## 保存与交付

先对照共读材料检查：重要认识及其证据和条件已保留；读者原话没有被改写成 AI 的判断；假设、分歧与未验证部分仍可辨认。用简洁、连贯的中文表述，保留必要的英文术语。

按 README 的约定写入目标笔记，完成索引与链接维护。局部续写只改相关内容；写入失败或结果不明时先检查已保存状态，再决定是否重试，避免重复创建。

读取保存结果，核对受影响的文字、图表和链接。完成归档后返回可打开的笔记位置，简述本次形成或修正的认识，以及仍值得继续讨论的问题。仅完成草稿时明确当前成果与待完成步骤。
