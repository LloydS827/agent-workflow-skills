# 交付检查

先检查内容，再检查最终文件。检查记录留在内部，交付说明只保留影响使用的事项。

## 外部读者能否独立使用

把自己放在第一次接触项目、没有内部账号的收件人位置，分别打开每份对外交付物。只看该文件，能否说清项目对象、拟作的决定、结论如何得出，以及适用条件？把回答所需的事实放入正文、图表说明或文件内的附录。

- 逐一查看首次出现的非通用缩写和编号。专业术语给全称及必要解释；团队内部代号直接换成实际名称。确需引用的公开标准编号附名称与用途。无法核实的简称和“合格”等判断先回到原始依据核对。
- 查看所有链接、脚注、图注、备注、批注和工作表（含隐藏内容与外部公式引用）。交付副本中移除内部工单、私有页面、本机路径、协商记录、修订痕迹及原始内部附件。仅保留读者可公开访问的必要来源，核对访问性；无法核实时将可披露的依据写进文件，把链接留在内部。文件即使离线阅读也能理解关键结论。
- 内部保留主张与原始证据的对应关系。对外引用项目自测结果时，在披露范围内交代对象、工况、样本量、方法、结果和局限。现场照片使用原图、准确场景与图注，示意图标明性质。

## 内容检查

- 按读者用途检查覆盖：正文回答了什么问题，支持什么判断，是否缺少必要依据或条件。
- 对重要技术主张回溯对象、场景、方法、数据与来源；核对版本和适用范围。建议、目标、估算与实测结果仍可区分。
- 重新核算影响结论的数字、比例、金额和单位；跨材料核对指标、范围、阶段与金额。
- 检查内部话术是否移除，同时确认必要的不确定性没有随之消失。
- 检查模板用途：只作为素材的文件不自动成为风格模板；用户指定的风格与格式优先。
- 图片来源与实际场景一致，裁剪不改变证据含义；示意图不会被误认为现场照片或实测结果。
- 用自然段讲明判断，标题简洁，表格用于真正可比较的数据。把未定费用写成估算依据与细化条件。检查范围、单位、分项、小计和合计的一致性。

## 文件检查

| 交付物 | 实际检查 |
| --- | --- |
| Word / PDF | 渲染并查看各页，检查字体、标题、分页、表格、图像、链接与裁剪 |
| 演示文稿 | 查看各页，检查信息层次、文本溢出、图像裁剪、字号与演示可读性；需要编辑的内容可编辑 |
| 工作簿 / 预算 | 重算并试改代表性输入，核对公式、单位、小计与合计。检查每张表的列宽、数字格式、冻结表头、打印区域、重复标题行及分页 |
| Markdown | 检查结构、主张与来源、链接和实际阅读方式，无需为检查额外派生文档 |

按对应文件技能完成具体操作。修改后复查受影响内容和依赖；无需反复渲染完全未变的页面或工作表。

只在正式目录交付指定格式及用户需要的可编辑源文件。把内部处理记录、渲染预览及旧稿留在正式交付之外，保留原材料和历史版本。说明实际文件入口，检查未能完成时指出具体影响。
