# 交付检查

先检查内容，再检查最终文件。检查记录留在内部，交付说明只保留影响使用的事项。

## 内容检查

- 按读者用途检查覆盖：正文回答了什么问题，支持什么判断，是否缺少必要依据或条件。
- 对重要技术主张回溯对象、场景、方法、数据与来源；核对版本和适用范围。建议、目标、估算与实测结果仍可区分。
- 重新核算影响结论的数字、比例、金额和单位；跨材料核对指标、范围、阶段与金额。
- 检查内部话术是否移除，同时确认必要的不确定性没有随之消失。
- 检查模板用途：只作为素材的文件不自动成为风格模板；用户指定的风格与格式优先。
- 图片来源与实际场景一致，裁剪不改变证据含义；示意图不会被误认为现场照片或实测结果。

## 文件检查

| 交付物 | 实际检查 |
| --- | --- |
| Word / PDF | 渲染并查看各页，检查字体、标题、分页、表格、图像、链接与裁剪 |
| 演示文稿 | 查看各页，检查信息层次、文本溢出、图像裁剪、字号与演示可读性；需要编辑的内容可编辑 |
| 工作簿 / 预算 | 重算，检查公式、合计、单位与引用；用代表性输入变化验证结果更新，再检查各工作表及必要打印区域 |
| Markdown | 检查结构、主张与来源、链接和实际阅读方式，无需为检查额外派生文档 |

按对应文件技能完成具体操作。修改后复查受影响内容和依赖；无需反复渲染完全未变的页面或工作表。

最后确认：文件能打开，目标内容完整，本次各交付物事实一致，输出位置明确。交付目录只含有用途的文件，原材料保留；未经用户要求不删除旧版。未执行的检查写明具体范围，不能以“生成成功”代替质量判断。
