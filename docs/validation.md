在项目根目录运行：

```sh
python3 scripts/check.py
python3 scripts/check.py --baseline
```

常规检查核对 技能目录索引、名称与描述、Codex 调用策略、Markdown 相对链接和常见本机路径或私有 Notion 链接。`--baseline` 额外核对全部导入文件的路径、SHA-256 与上游许可文件。文件经过中文修订后，仍可运行常规检查；快照用于追溯差异。[导入清单](source-baseline.json)

迁移时将新项目单独复制到临时目录，从项目外运行上述校验，通过。随后在临时副本中分别移除共享参考、原型说明及诊断脚本模板，或改变显式和隐式技能的调用配置，检查均指出受影响项。仅改写一段技能正文时，常规检查通过，快照检查报告了具体文件的变化。
