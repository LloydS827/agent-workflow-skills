# 技能目录

**主流程**　澄清需求 → 首次初始化 → 形成方案 → 简化 → 组织执行 → 按任务实施与验收。研究可以穿插各环节。执行证据回到原 Issue，改变技术路线的结论回到原方案。

| 要做的事 | 项目内入口 | 交给下一步的成果 |
| --- | --- | --- |
| 澄清日常需求 | [grill-with-docs](../skills/grill-with-docs/SKILL.md) | 已决定的目标、术语、约束和未决问题 |
| 跨会话梳理复杂问题 | [wayfinder](../skills/wayfinder/SKILL.md) | 决策地图及有依赖关系的子 Issue |
| 为项目建立入口 | [init-notion-project](../skills/init-notion-project/SKILL.md) | Notion 项目主页和必要区域 |
| 把共识写成方案 | [to-notion](../skills/to-notion/SKILL.md) | 可供简化的候选方案，或已回读的项目证据记录 |
| 判断哪些工作值得做 | [simplify](../skills/simplify/SKILL.md) | 只审查时给建议；定稿时给出本轮可执行范围与验收条件 |
| 拆解或调整执行安排、回写进展、复盘阶段 | [to-pm](../skills/to-pm/SKILL.md) | 从简化定稿拆出的 Issue 与 ticket、原任务反馈或阶段结论 |
| 实现软件行为 | [implement](../skills/implement/SKILL.md) | 指定范围的实现、测试、代码审查与可回写原票的证据 |
| 调查技术问题 | [research](../skills/research/SKILL.md) | 带一手来源的研究记录 |
| 交付报告、汇报或预算 | [project-docs](../skills/project-docs/SKILL.md) | 外部读者可独立使用、按指定格式检查过的材料 |

**补充入口与支撑技能**

| 场景 | 项目内技能 |
| --- | --- |
| 澄清与记录 | [grilling](../skills/grilling/SKILL.md) 按轮次追问，[domain-modeling](../skills/domain-modeling/SKILL.md) 维护术语与关键决策 |
| 验证设计想法 | [prototype](../skills/prototype/SKILL.md) 用原型检验交互或状态规则，[codebase-design](../skills/codebase-design/SKILL.md) 推敲模块接口 |
| 检查实现 | [tdd](../skills/tdd/SKILL.md) 用行为测试驱动实现，[code-review](../skills/code-review/SKILL.md) 审查规范与需求符合度，[diagnosing-bugs](../skills/diagnosing-bugs/SKILL.md) 诊断故障和性能退化 |
| 组织工程工作 | [triage](../skills/triage/SKILL.md) 分类已有请求，[implement-all](../skills/implement-all/SKILL.md) 核对原票和项目证据，安排并行实现并集成验收，[improve-codebase-architecture](../skills/improve-codebase-architecture/SKILL.md) 选择结构改进点 |
| 论文精读 | [paper-assistant](../skills/paper-assistant/SKILL.md) 按读者进度解构论文，围绕原文讨论并续写阅读笔记 |
| 学习与交接 | [teach](../skills/teach/SKILL.md) 组织学习，[handoff](../skills/handoff/SKILL.md) 交接会话，[retro](../skills/retro/SKILL.md) 从实践中改进工具和指令 |
| 配置与维护 | [setup-matt-pocock-skills](../skills/setup-matt-pocock-skills/SKILL.md) 配置工程项目的 tracker 与领域文档，[writing-for-agents](../skills/writing-for-agents/SKILL.md) 编写技能与 Agent 指令 |
| 技能建设 | 显式调用 [skill-builder](../skills/skill-builder/SKILL.md)，从经验或固定需求新建技能，或针对已有技能的反馈做修订和试用 |
